CENTRO NOTIFICHE

NUOVA NOTIFICA

L'invio scrive in notifications/global oppure notifications/{uid} secondo le regole Firebase.

INTEGRAZIONE NOTIFICATION.JSON

Nel pacchetto fornito non è presente un file notification.json. L'app attuale legge le notifiche direttamente da Firebase Realtime Database. Per mantenere compatibilità con un eventuale endpoint JSON di meowgo.it occorre conoscerne URL, formato e modalità di pubblicazione: non scriverò su un file remoto inventando un endpoint.

Le notifiche inviate dal pannello saranno compatibili con il sistema Firebase attuale, non con un ipotetico JSON statico.
